# Ping-Pong-Game

I have made a Ping Pong game built with **Python** and **Pygame**. It is neon styled. Play against a friend or take a challenge by beating the computer across different levels.

# Features

1. Two Game Modes
   - Play with a friend
   - Play against computer
2. Computer Difficulties
   - Easy
   - Medium
   - Hard
3. Crazy Ball Speed & Sharp Bounce
   - Ball gets faster with each hit
   - Hit the ball and it will have sharp bounce
4. Visual Effects
   - Glowing paddles
   - Glowing ball and trial
   - Hit effects
   - Animated difficulty effects
   - Retro style main screen
5. Pause Menu
6. First to 10 points wins

# Installations

You can install this game right on your computer. You just simply have to go over to the Release section in this repository and download the **Ping.Pong.exe** file as it is the official executable file. If you download this and your computer tells you this is by an unknown publisher then click more info and click run anyway. This happens because the app is not registered. Then you can just have fun playing it!
